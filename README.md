DESCRIPCION:
Este repositorio contiene el desarrollo del Desafío 1 de Informática II, que consistió en implementar una versión del juego Sweet Crush utilizando C++ y manipulación de bits.
El principal reto fue almacenar las fichas del tablero utilizando solamente 3 bits por ficha, en lugar de utilizar una matriz convencional.
Además, el programa permite eliminar fichas, detectar combinaciones, aplicar gravedad, generar nuevas fichas y modificar las dimensiones del tablero durante el juego.

ORGANIZACION DEL REPOSITORIO:

Avance_1 - Almacenamiento del tablero
Implementé la creación del tablero en memoria dinámica y las funciones para obtener y modificar fichas mediante operaciones bitwise.

Avance_2 - Generación y visualización
Agregué el llenado aleatorio del tablero y la visualización de las fichas mediante las letras A, B, C, D, E y F.

Avance_3 - Combinaciones
Implementé la detección y eliminación de combinaciones horizontales y verticales de tres o más fichas iguales.

Avance_4 - Gravedad y cascadas
Agregué la gravedad, el relleno de espacios vacíos y la repetición automática del proceso cuando aparecen nuevas combinaciones.

Avance_5 - Modificación del tablero
Implementé las funciones para eliminar fichas individuales y agregar o eliminar filas y columnas en cualquier posición.
También incorporé el control de memoria mediante la regla del 65 %.

Versión final
Integré todas las funcionalidades anteriores en un juego interactivo.
Esta versión incluye el menú, la visualización binaria, los contadores, las validaciones y el sistema de puntuación.

Consideraciones finales:
Este proyecto me permitió comprender mejor el manejo de memoria dinámica, la manipulación de bits y la importancia de organizar un programa en diferentes módulos.
El repositorio conserva los avances del desarrollo para mostrar cómo fui construyendo la solución hasta llegar a la versión final.
Cada avance cuenta con su propio README, sin embargo, recomiendo como minimo visualizar el README de la version final.
